\section{Experimental Setup}
\label{sec:experimental_setup}

\textbf{Software.} All agents and games are implemented in Python and tested with \texttt{pytest} on Python $3.10$ and $3.13$ in continuous integration. Every match result in this paper is produced by one runner, \texttt{experiments/run.py}, from a YAML file that fixes the game, the two agents, their parameters, and their budgets. A list of values in the file is expanded into one matchup per combination. The runner writes one CSV row per game with the winner, the number of plies, and the nodes and time used by each side, and the tables are generated from these files by scripts rather than copied by hand. Timings depend on the machine and on the number of parallel games, so speeds are compared only within one experiment.

\textbf{Reproducibility.} Each experiment has a root seed ($2026$), from which the seed of every game and every agent is derived deterministically, so a configuration can be rerun game by game, whether the games run in one process or in parallel.

\textbf{Protocol.} Each configuration is played for at least $50$ games, and most use $200$. The first move alternates between the two agents. On Gomoku the first two plies are random candidate moves, and both games of a pair share the same opening, so that deterministic agents do not replay one game and both colors see the same positions. Opponents are a uniformly random player, perfect Minimax (on $3\times 3$), a fixed MCTS baseline, and alpha-beta. The exploration constant is reported on the $[0, 1]$ reward scale of the assignment, $c \in \{0.5, 1.0, 1.4, 2.0\}$, which corresponds to $2c$ in our code (Section~\ref{subsec:math_uct}); the iteration budgets range from $100$ to $5\,000$ for the survey of $c$.

\textbf{Metrics and statistics.} We report the win rate, the draw rate, the score (win $1$, draw $1/2$, loss $0$), the nodes or simulations per move, and the time per move. Win rates come with $95\%$ Wilson score intervals. Two configurations are compared with the two-proportion $z$-test, and differences in mean score between paired games with a bootstrap $95\%$ interval. A head-to-head score is compared with $1/2$ by a $z$-test whose variance is taken under the null hypothesis, so that a sweep such as $60$ wins in $60$ games still yields a finite statistic.
